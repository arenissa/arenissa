# Привет! Я Светлана 👋

Учитель русского языка и литературы. Помогаю школьникам готовиться к ОГЭ и ЕГЭ, а себе — не утонуть в проверке тетрадей и подготовке материалов: осваиваю вайб-кодинг и делаю цифровые помощники для уроков вместе с нейросетями.

## Что я делаю

- **Готовлю к экзаменам** — словарные слова, паронимы, тропы и фигуры речи, итоговое собеседование, сочинения и изложения.
- **Создаю цифровые тренажёры** — интерактивные упражнения для повторения тем ОГЭ/ЕГЭ, которые учитывают особенности конкретного класса.
- **Анализирую результаты** — превращаю таблицы диагностических и предэкзаменационных работ в наглядные отчёты с методическими выводами.

## Инструменты, с которыми работаю

- OpenCode + ChatGPT / DeepSeek / GigaChat — нейросети как «конструктор» тренажёров и ассистент вайб-кодинга;
- HTML / CSS / JavaScript — простые локальные веб-приложения для урока;
- Google Таблицы и Excel — работа с результатами учеников.

## Проект в работе (портфолио)

> **«Цифровые тренажёры для подготовки к ГИА с помощью ИИ»** — конструктор интерактивных упражнений по русскому языку для повторения тем ОГЭ/ЕГЭ. Учитель описывает тип задания, а нейросеть генерирует упражнения, варианты ответов, подсказки и объяснения ошибок. Готовлю линейку тренажёров: словарные слова, паронимы, тропы, орфография — под конкретный класс и программу.
