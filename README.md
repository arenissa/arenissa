## Проект в работе (портфолио)

> **«Цифровые тренажёры для подготовки к ГИА с помощью ИИ»** — конструктор интерактивных упражнений по русскому языку для повторения тем ОГЭ/ЕГЭ. Учитель описывает тип задания, а нейросеть генерирует упражнения, варианты ответов, подсказки и объяснения ошибок. Готовлю линейку тренажёров: словарные слова, паронимы, тропы, орфография — под конкретный класс и программу.
